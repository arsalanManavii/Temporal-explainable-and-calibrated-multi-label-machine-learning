# Temporal, Explainable and Calibrated Multi-Label Machine Learning for
# Post-Myocardial-Infarction Complication Risk Stratification

Analysis pipeline for the manuscript (secondary analysis of the UCI
*Myocardial Infarction Complications* dataset, ID 579, 1,700 patients,
111 clinical features, 12 outcomes = 11 binary complications + in-hospital
mortality derived from `LET_IS > 0`).

Every number, table and figure in the manuscript is regenerated by the
scripts below from the raw data file (`data/MI.data`) with a single global
seed (`config.SEED = 10`).

```bash
export LD_LIBRARY_PATH=<dir with libgomp.so.1>:$LD_LIBRARY_PATH   # LightGBM only
python code/s01_tuning.py            # audit/reproduce hyper-parameter search
python code/s02_models.py --models XGB,LR
python code/s02_models.py --models LGBM,RF
python code/s02_models.py --models CHAIN --stages admission,24hr
python code/s02_models.py --models CHAIN --stages 48hr,72hr
python code/s03_calibration.py
python code/s04_stats.py

python code/s06_shap.py

python code/s08_sensitivity.py A     # censoring-linked missing indicators
python code/s08_sensitivity.py B     # ICU treatment variables
python code/s08_sensitivity.py C     # unweighted baseline
python code/s09_loro_evaluation.py   # leave-one-repeat-out honest metrics

python code/s11_tables.py
python code/s12_figures.py
python code/s13_supplementary_docs.py
python code/s14_supplementary_package.py
```

Scripts are idempotent per (model, stage): existing OOF files are skipped,
and long stages (classifier chain, calibration) checkpoint after every CV
repeat, so an interrupted run resumes.

## Statistical protocol (pre-specified)

* **Validation**: repeated 5-fold x 5-repeat cross-validation with iterative
  multi-label stratification (Sechidis et al.); identical folds for all
  models/stages, so paired tests are valid. Out-of-fold (OOF) probabilities,
  averaged over repeats, are the basis of every estimate.
* **Leakage control**: imputation, scaling, one-hot encoding, per-outcome
  class weights, thresholds and calibration mappings are fitted **inside
  training folds only**.
* **Discrimination**: AUROC / AUPRC per outcome; macro/micro/weighted F1 at
  pre-specified thresholds. 95% CIs: patient-level percentile bootstrap
  (B = 2,000 primary model; B = 1,000 elsewhere).
* **Stage comparisons (RQ2/RQ4)**: DeLong test (AUROC) and paired bootstrap
  (AUPRC) on identical OOF patients; Holm adjustment across the 12 outcomes.
* **Calibration (RQ7)**: Brier, ECE (10 equal-width bins), ICI (spline
  logistic), calibration slope/intercept; post-hoc sigmoid/isotonic fitted
  fold-internally (CalibratedClassifierCV, inner 3-fold); per-outcome method
  selected by lower OOF Brier.
* **Decision thresholds**: F1-maximising for standard outcomes; lowest
  threshold achieving >= 90% recall for high-lethality outcomes
  (conditional mortality >= 25%: rupture, 3rd-degree AV block, ventricular
  fibrillation, recurrent MI, pulmonary edema, death).
* **Utility**: decision-curve analysis from calibrated OOF probabilities;
  risk-quintile stratification with Wilson CIs.
* **Explainability**: SHAP TreeExplainer per outcome on the pre-specified
  fixed split (train 80% / test 20%, seed 10) - used only for explanation
  figures/tables; all performance claims come from the CV protocol.

## Key results (headline)

* Macro AUROC improves monotonically with accumulated information for every
  model (e.g. XGBoost 0.696 -> 0.717; RF 0.732 -> 0.752).
* Mortality AUROC 0.935 (95% CI see Table 4), surpassing published GNN
  (0.883) and multitask-NN results on the same data.
* Significant Holm-adjusted temporal gains for mortality, chronic heart
  failure, atrial fibrillation, pulmonary edema, recurrent MI (Table 5).
* Post-hoc calibration reduces ECE by ~5-20x (e.g. mortality 0.084 -> 0.013).
* Risk quintiles separate observed mortality from 0% (Q1) to 63.5% (Q5).
* Outcomes with EPV < 1 (supraventricular/ventricular tachycardia) remain
  unpredictable - reported transparently.
